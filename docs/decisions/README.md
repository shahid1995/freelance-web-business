# Business Decisions

Material permanent business decisions belong here.

Filename pattern:

- `YYYY-MM-DD-short-title.md`

For example: `2026-10-04-public-contact-copy.md`

This follows the convention set in
`docs/conventions/repository-and-documentation.md`, which supersedes the
earlier numbered-ADR examples.

Each decision should record context, alternatives considered, final decision, consequences, and status.
