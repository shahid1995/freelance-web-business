# Delivery

Client delivery guidance, project lifecycle, discovery, scope, milestones, QA, handover, and closure practices belong here.

Individual client project implementation remains in the client's separate repository.

## Phase 3 components

- client-discovery.md — discovery process, questions, outputs, boundaries, and handoff to scope
- scope — planned next component
- milestones — planned next component
- QA — planned next component
- handover — planned next component
- project closure — planned next component

## Delivery lifecycle

Accepted opportunity → Delivery handoff → Discovery → Scope → Milestones → Implementation and QA → Handover → Project closure

Discovery must not silently expand the accepted commercial scope. Material changes require the agreed change-control process.

Client-specific records belong in the client's separate project repository or another explicitly approved operating location, not in this public business repository.
