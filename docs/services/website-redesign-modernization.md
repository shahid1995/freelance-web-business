# Website Redesign / Modernization

## Purpose

Improve an existing website's structure, interface, responsiveness, usability, or maintainability without assuming the site must be rebuilt completely.

## Ideal client / use case

Suitable for organizations with:

- An outdated visual interface
- Poor mobile experience
- Confusing navigation or information architecture
- Inconsistent page designs
- A site that no longer matches the current business
- A maintainability problem requiring structured modernization

## Core deliverables

Depending on scope:

- Current-state review of agreed website areas
- Redesigned information structure or page hierarchy where required
- Updated responsive layouts
- Modernized components and interaction patterns
- Improved navigation and calls to action
- Content/layout migration for agreed pages
- Removal or replacement of agreed obsolete elements
- Updated implementation and agreed handover material

## Typical scope

The project should identify which of the following is being changed:

- Visual design
- Information architecture
- Responsive behavior
- Navigation
- Content presentation
- Components
- Selected integrations
- Front-end implementation
- CMS/content structure

A redesign does not automatically include every legacy page or system component.

## Boundaries / exclusions

Not included unless explicitly scoped:

- Rebranding or creation of a new brand identity
- Complete backend replacement
- Unrelated feature development
- Large content rewrites
- Migration of every historical page or asset
- Guaranteed SEO ranking improvement
- Guaranteed traffic, leads, or conversion improvement
- Ongoing maintenance after the project

## Optional extensions

- Larger page migration
- CMS restructuring
- Performance optimization
- Accessibility improvements
- Analytics review/configuration
- Technical debt cleanup in agreed areas
- New page templates
- Incremental post-redesign maintenance

## Client inputs

The client should provide:

- Existing website access
- Existing source/materials where applicable
- Pages or areas to retain, change, or remove
- Current business/brand direction
- Known user or business complaints
- Existing analytics or feedback when available

## Acceptance criteria

The redesign is complete when:

1. The agreed existing areas are updated according to the approved scope.
2. Agreed navigation and user flows work correctly.
3. Responsive behavior meets the agreed expectations.
4. Approved content and assets are retained, replaced, or migrated as specified.
5. In-scope integrations continue to work or are updated as agreed.
6. Known critical in-scope defects are resolved or documented.
7. Agreed handover material is provided.

A modernization project does not guarantee a particular business metric unless that metric is explicitly defined and controlled within the project scope.
