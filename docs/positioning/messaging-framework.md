# Public Messaging Framework

**Status:** Phase 0.3  
**Last updated:** 2026-09-27

## Message hierarchy

### Primary message

**Build, modernize, and maintain a better web presence.**

### Supporting message

**Business websites, landing pages, and focused web applications with clear scope and practical implementation.**

### Proof themes

Public proof should demonstrate:

- Before/after improvement where evidence is available
- Clear screenshots and project descriptions
- Functional examples
- Responsive behavior
- Relevant technical capabilities
- Honest project scope and role
- Client feedback only when permission exists

## Messaging by need

### New website
"Build a modern business website that clearly presents your company, services, and next steps."

### Landing page
"Create a focused landing page around a specific offer, audience, or campaign objective."

### Redesign
"Modernize an existing website so its structure, interface, and responsive experience better match the business today."

### Custom application
"Build focused web functionality for workflows that a standard marketing website cannot handle."

### Dashboard or portal
"Turn operational information or user workflows into a practical web dashboard or portal."

### Maintenance
"Keep an existing website useful with fixes, improvements, updates, and incremental modernization."

## Language to prefer

- Clear
- Modern
- Responsive
- Practical
- Maintainable
- Structured
- Reliable
- User-friendly
- Defined scope
- Focused web application

## Language to avoid unless evidence supports it

- Best
- #1
- Guaranteed
- Guaranteed conversions
- Guaranteed leads
- Guaranteed revenue
- Enterprise-grade (unless the specific deliverable supports the claim)
- World-class
- Revolutionary
- Award-winning
- Proven results (unless specific evidence is available)

## Call-to-action direction

Early public calls-to-action should invite a concrete next step, such as:

- Discuss your website project
- Request a project estimate
- Review your website needs
- Discuss a redesign
- Discuss a custom web application

The final CTA and conversion flow will be defined during the public portfolio phase.
