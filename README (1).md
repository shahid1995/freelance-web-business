# Freelance Web Development Business

A long-term operating system for a professional web-development freelance business.

## Purpose

This repository contains the business-level source material used to build, operate, improve, and eventually scale the freelance web-development business. It is intentionally separate from individual client repositories.

## Business Positioning

**Modern Websites & Web Applications**

Initial service areas:

- Business websites
- Landing pages
- Website redesign and modernization
- Custom web applications
- Maintenance and improvements

## Repository Boundaries

This repository is for reusable business assets, decisions, templates, portfolio specifications, operating procedures, and the public portfolio website when implemented.

Individual client projects must use separate repositories.

Never store secrets, client credentials, private client documents, production credentials, or sensitive customer information here.

## Authority Model

- **Founder:** final authority over business decisions.
- **GitHub:** implementation and project source of truth.
- **Second Brain (Obsidian):** knowledge, context, research, and decision context.
- **Execution agents/tools:** implementation support only; they do not redefine accepted business decisions.

## Current Phase

**Phase 0 — Foundation**

Current milestone: **0.1 — Dedicated GitHub repository and initial operating structure**

## Planned Structure

```text
docs/          Business strategy, positioning, services, pricing, sales, delivery, quality, finance, decisions
portfolio/     Portfolio projects, screenshots, and case studies
templates/     Reusable client-facing and delivery templates

```

## Public Repository Note

This repository is intended to remain **public** for accessibility and integration. Public visibility does not grant reuse rights to the business materials unless a separate license is explicitly provided.
