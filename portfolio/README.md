# Portfolio System

This directory contains the business portfolio system: project records, screenshots/evidence, case studies, and the portfolio index.

The portfolio must represent work truthfully.

Every portfolio item must identify its ownership/status clearly:

- Client work
- Founder-owned/internal work
- Demonstration/concept work

Do not present internal, demonstration, or concept work as client work.

## Portfolio system

- portfolio-index.md — registry of portfolio items and publication status
- project-template.md — standard project record template
- case-study-template.md — standard case-study template
- screenshot-standards.md — evidence and screenshot standards
- projects/ — individual project records
- screenshots/ — approved portfolio screenshots and visual evidence
- case-studies/ — client-facing or public case studies

A portfolio item can exist in the internal repository without being ready for public publication.
