# Portfolio Screenshots

This directory contains screenshots that have passed the portfolio screenshot standards and are approved for the corresponding project record.

## Organization

When a project has multiple screenshots, group them in a project directory:

portfolio/screenshots/project-name/

Use lowercase kebab-case filenames.

Examples:

- homepage-desktop.png
- homepage-mobile.png
- dashboard-overview.png
- redesign-before.png
- redesign-after.png

## Rules

Screenshots must:

- represent the actual work or clearly labeled demonstration/concept;
- support a specific portfolio claim;
- contain no credentials or secrets;
- contain no unnecessary private customer data;
- satisfy the standards in portfolio/screenshot-standards.md;
- have publication permission where required.

Do not add screenshots just to increase portfolio volume.
